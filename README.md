DNA Nucleotide Counter:
This project is a simple Python program that counts the number of A, T, G, and C nucleotides in a DNA sequence.

Objective
To count the occurrence of each nucleotide (A, T, G, and C) in a given DNA sequence.
DNA Sequence = AATGCCGTAAAGGGCTGCATG

Output:
A: 6
T: 4
G: 7
C: 4

How It Works:

The program takes a DNA sequence as input and uses Python's "count()" function to count the number of each nucleotide.
